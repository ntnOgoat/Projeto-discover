# DevLinks

Página com os meus links principais, feita no curso **Discover** da Rocketseat. A ideia é juntar GitHub, LinkedIn e e-mail em um lugar só, parecido com o Linktree.



## O que tem no projeto

- Foto, nome, usuário e bio
- Três links: GitHub, LinkedIn e e-mail
- Botões no estilo "tecla de teclado": o botão afunda quando a gente clica
- Botão para trocar entre tema claro e escuro
- O tema escolhido fica salvo no navegador (se ainda não escolheu, usa o tema do sistema)
- Botão para copiar o link da página
- Layout responsivo, funciona no celular e no computador

## Tecnologias

- HTML
- CSS (variáveis para os temas)
- JavaScript (DOM e localStorage)

## Como rodar

1. Clone o repositório:

```bash
git clone https://github.com/ntnOgoat/devlinks.git
```

2. Abra a pasta no VS Code.
3. Abra o `index.html` no navegador ou use a extensão **Live Server**.

Não precisa instalar nada.

## Como personalizar

No `index.html`, troque o nome, a bio e os links pelos seus. A foto de perfil é puxada direto do GitHub, então basta trocar o usuário no endereço da imagem.

Para mudar as cores, edite as variáveis no começo do `style.css`.

## Estrutura

```
devlinks/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Publicando no GitHub Pages

1. No repositório, vá em **Settings > Pages**
2. Em **Branch**, escolha `main` e a pasta `/ (root)`
3. Salve e espere alguns minutos. O link do site vai aparecer na mesma tela

## O que eu pratiquei

- Estruturar uma página com HTML semântico
- Usar variáveis CSS para fazer tema claro e escuro
- Mexer no DOM com JavaScript
- Guardar dados no `localStorage`
- Deixar o layout responsivo
